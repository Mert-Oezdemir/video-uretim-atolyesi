# Ajan yönergeleri

Bu dizin, ana Video Üretim Atölyesi iş akışına dokunmayan opsiyonel bir animasyon entegrasyonudur.
Kullanıcı onayı olmadan dış servislerde kredi harcama, proje dışı dosya değiştirme veya
Blender MCP üzerinden bilinmeyen Python kodu çalıştırma. Önce tek kare önizleme öner.
Yerelde doğrulanmayan yazılımı kuruldu diye raporlama.
